Connect your bot

In your bot’s remote MCP settings, choose Streamable HTTP and paste this endpoint. Select Bearer authentication and paste your bot API key.

Ask your bot to use generate_image for a new image or start_localization for a source image and target market. Use get_job until the images are ready.

HTTP API
Send Authorization: Bearer YOUR_BOT_KEY with every request. For POST requests use Content-Type: application/json.


POST /api/v1/generate
{"prompt":"A ceramic cup beside a sunlit window"}

POST /api/v1/localize
{"image_urls":["https://your-site.com/ad.png"],
 "target_languages":["Greece"],"model":"grok"}

GET /api/v1/options
GET /api/v1/jobs/{job_id}


Both POST endpoints return a job ID. Poll every five seconds until done or failed. Read images from results[].url. For localization, the options endpoint lists supported markets. Reuse an idempotency_key when retrying a localization request.


Bot keys have no daily or per-minute app quota. For localization, send up to 20 sources and 100 source × market results per job. Submit additional jobs for larger batches. Provider credits, provider throughput and hosting limits apply.
